# Law7
## Открытая база правовых документов для AI-ассистентов

---

*Phase 1 - Россия (операционная) | Лицензия: AGPL-3.0*

---

## Проблема

AI-ассистенты имеют ограничения при работе с юридическими вопросами:

- Используют **устаревшие данные** из обучающей выборки
- **Галлюцинируют** несуществующие правовые нормы
- Дают **общие ответы** без конкретных ссылок на статьи
- Не могут **отследить изменения** законодательства во времени

---

## Решение - Law7

**Миссия**: Создать открытую, глобальную, децентрализованную базу правовых документов

**Ключевые особенности**:
- Данные только из **официальных государственных источников**
- **Полная история версий** статей (с 2011 года)
- Интеграция с AI через протокол **MCP** (Model Context Protocol)
- **Семантический поиск** по содержанию документов

---

## Архитектура

```
┌─────────────────┐    ┌──────────────────┐    ┌─────────────┐    ┌──────────────┐
│ Python Pipeline │ -> │ PostgreSQL +     │ -> │ TypeScript  │ -> │ AI           │
│                 │    │ Qdrant + Redis   │    │ MCP Server  │    │ Assistants   │
└─────────────────┘    └──────────────────┘    └─────────────┘    └──────────────┘
```

**Компоненты**:
- **Data Pipeline** (Python): Краулер, парсер PDF/HTML, генератор эмбеддингов
- **База данных**: PostgreSQL (метаданные), Qdrant (векторный поиск), Redis (кеш)
- **MCP Server** (TypeScript): 7 инструментов для запросов

## Консолидационный движок

Отслеживает исторические версии правовых статей:

- Получает поправки с pravo.gov.ru
- Парсит документы изменений (дополнения, отмена, редактирование)
- Применяет изменения для создания исторических снимков
- Ведёт журнал аудита в таблице `amendment_applications`

**Пример вопроса**: *"Какой была статья 155 ЖК РФ в 2020 году?"*

## Источники данных

Только официальные государственные источники:

| Источник | Описание |
|----------|----------|
| pravo.gov.ru | Официальный портал правовой информации |
| kremlin.ru | Сайт Президента РФ |

Каждый документ:
- Хешируется для верификации
- Снабжён временной меткой загрузки
- Перекрёстно ссылается на постоянный URL
